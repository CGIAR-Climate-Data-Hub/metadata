# Metadata Templates

Use these YAML files as starting points for common record shapes:

- `full-standard.yaml` - complete field reference with every core field and extension section.
- `spatial-grid.yaml` - gridded, raster, Zarr, NetCDF, or COG-style data.
- `spatial-geometry.yaml` - vector/table assets that contain embedded geometries.
- `spatial-indexed.yaml` - tabular data keyed to external spatial units or locations.

`spatial.geography` alone is a place facet. Use one of the spatial templates when the record
describes spatial data with a footprint, geometry column, spatial resolution, or spatially indexed
rows.
